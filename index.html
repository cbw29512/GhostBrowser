What Is Ghost Browser

A New Model for
Private Browsing

Modern browsers are designed to remember — cookies, cache, local storage, session tokens. Ghost Browser takes the opposite approach: every browsing session runs inside a controlled, disposable runtime that leaves no persistent artifacts on the host system when it exits.

Built on Docker and Kasm containerization, Ghost Browser wraps the browser process inside an isolated environment. An encrypted credential vault with per-domain pinning means sensitive data never touches disk in plaintext, and per-tile ad-blocking controls give granular control over what traffic even reaches the container.

This isn't a daily-use browser replacement — it's a research and experimentation platform for the security community to study, test, and advance the science of ephemeral browsing architecture.

Core Design Pillars

Built Around One Rule:
Sessions Don't Survive

🔒

Encrypted Credential Vault

Per-session, per-domain credential storage using bank-grade encryption. Credentials are never written to disk in plaintext and are purged at teardown.

🐳

Docker Container Isolation

Each browsing session runs inside a fresh Docker/Kasm container. The host filesystem is never touched by browser state, cookies, or cache data.

🔗

Domain Pinning

Chrome's --host-rules flag is used to enforce domain-level routing rules, preventing session data from leaking across untrusted origins.

🛡️

Per-Tile Ad Blocking

Granular ad-block controls on a per-container tile basis. Block tracking scripts and ads in individual sessions without affecting others.

💾

RAM-First Architecture

Session data lives in memory, not on disk. Ghost Browser's long-term vision prioritizes volatile storage strategies that evaporate with the process.

🔬

Open Research Platform

MIT licensed and fully transparent. Every architectural decision is documented so security researchers can study, fork, and build upon the foundation.

Runtime Isolation

Kasm Workspaces provides a browser-in-container runtime accessed via a web interface. The container is spun up fresh per session and destroyed completely on exit.

Docker Kasm Ephemeral

Network & Trust Layer

Chrome's --host-rules flag enforces domain pinning. Combined with per-tile ad-block, outbound traffic is tightly scoped to only what the session explicitly needs.

Core Application

The orchestration layer is pure Python — chosen for readability, extensibility, and the rich ecosystem of security and networking libraries available to researchers building on top of Ghost Browser.
